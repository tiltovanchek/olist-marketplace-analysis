# Проверка готовой версии

## Аналитический пайплайн

Полная сборка из исходных CSV выполнена в среде Python 3.13.1 с версиями из
`requirements.txt`. Пройдены 20 проверок качества и 22 теста.
Проверяются зерно витрин, отсутствие размножения денег при соединениях,
выбор одного отзыва, неизвестные даты, календарный срок доставки,
границы 90 дней и зрелость когорт. Результаты проверок качества сохранены
в `reports/data_quality.json`, параметры и хеши входов — в `reports/manifest.json`.

Численные выводы отчёта и исполненный ноутбук получены одним сборщиком.
Кластерный бутстрап использует 2000 повторений и фиксированное начальное значение 42.
Изменение подписей и представления графиков не меняет метод расчёта.

## Power BI

- Просмотрены все три страницы в Power BI Desktop: подписи, размещение фильтров,
  отсутствие наложений, значения карточек и строки таблицы отзывов.
- Данные успешно обновлены из четырёх CSV через параметр `ProjectRoot`.
- Выгрузка сервиса: 83 701 заказ и 546 уникальных календарных дат.
  Пять показателей сверены с SQL отдельно для каждого из 18 месяцев.
- Статическая проверка PBIR/TMDL прошла: 3 страницы, 24 визуала,
  16 мер DAX, источники, связь календаря и отсутствие пересечений.
  Результат — `powerbi/design_validation.json`.
- Сохранённый PBIX проверен как ZIP: повреждений нет, модель данных присутствует.
  Все 30 JSON определений отчёта и зарегистрированная тема совпали с PBIP.
  Бинарная модель PBIX не сравнивалась побайтово; её проверка основана на успешном
  обновлении данных, контрольных значениях и проверке исходных мер.

## Повторить проверки

После размещения исходных CSV и установки зависимостей выполните из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts/build_portfolio.py
.\.venv\Scripts\python.exe scripts/export_powerbi_service.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/validate_powerbi.py
```

Затем обновите данные в Power BI по [инструкции](../powerbi/README.md).
Статическая проверка не исполняет DAX и не заменяет просмотр отчёта в Desktop.
Проверки согласованности не устраняют ограничения исторического источника:
неизвестную прошлую историю, неполноту конца периода, отбор отзывов и отсутствие рандомизации.
